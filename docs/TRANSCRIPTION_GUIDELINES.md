# Transcription Guidelines — v1 (draft, freeze before Phase 1 ends)

Darija has no standard spelling. **Consistency matters more than "correctness"**: if two people write the same word differently, WER becomes meaningless. Every transcriber and every normalization function follows this file.

## 1. Script
- **Darija / Arabic words → Arabic script.**
- **French / English words → Latin script, standard spelling**, lowercase.
  - `نمشي للـ réunion متاع demain` ✅
  - `نمشي لل ريونيون` ❌
- **Fully integrated loanwords** that are pronounced the Tunisian way and used as Darija (e.g. كرهبة, تلفون, بلاصة) → Arabic script. Keep a shared list in `ml/resources/loanwords.tsv` and extend it by PR.

## 2. Arabic spelling rules
- No diacritics (tashkeel), no tatweel (ـ).
- Hamza normalization for scoring: أ إ آ → ا ; ى → ي at word end; ة kept as ة.
- Write words **as pronounced in Darija**, not the MSA equivalent:
  - `شنوة` not `ما هذا`, `برشا` not `كثيرا`, `توا` not `الآن`
- Common forms (use these exact spellings):
  | Meaning | Write |
  |---|---|
  | what | شنوة |
  | now | توا |
  | a lot | برشا |
  | why | علاش |
  | where | وين |
  | I want | نحب |
  | not / don't | ما … ش (e.g. `ما عنديش`) |
  | okay | باهي |
  | of / belonging to | متاع |
- Negation `ما...ش`: write `ما` separately, `ش` attached: `ما نجمش`.
- Definite article attached: `الكرهبة`.
- Extend this table only by PR, never ad hoc.

## 3. Numbers
- Write numbers as **digits**: `3 ساعات`, `25 دينار`, `rendez-vous 14h`.
- Phone numbers: digits, no spaces → anonymize in shared data (see Privacy).

## 4. Non-speech & disfluencies
| Event | Tag |
|---|---|
| Laughter | `[ضحك]` |
| Unintelligible | `[غير مفهوم]` |
| Background speech | ignore |
| Music / noise | ignore |
| Fillers (ممم، اه، euh) | **omit** |
| Repetitions / false starts | keep only the final complete word |
- Tags are **removed before WER scoring**.

## 5. Punctuation & case
- Training targets: light punctuation allowed (، ؟ .).
- **Scoring:** remove all punctuation, lowercase Latin text.

## 6. Personal information
- Replace names of private people with `[اسم]`, phone numbers with `[رقم]`, exact addresses with `[عنوان]` in any data that leaves the collection machine.

## 7. Arabizi output (app feature, not training target)
Generated by a deterministic transliteration from Arabic script:
| Arabic | Arabizi |
|---|---|
| ع | 3 |
| ح | 7 |
| خ | 5 |
| ق | 9 |
| ء / أ | 2 or a (word-initial: a) |
| ش | ch |
| غ | gh |
| ذ / ظ | dh |
| ث | th |
| ج | j |
| و | ou / w |
| ي | i / y |
Examples: `شنوة` → `chnowa`, `برشا` → `barcha`, `عسلامة` → `3aslema`. Latin words pass through unchanged. Tune the mapping with user feedback; it does not affect WER.

## 8. Quality control
- 10% of clips transcribed by two people; report agreement (WER between them). Target < 10%.
- Disagreements → discussion → update this file (new version) if needed.
