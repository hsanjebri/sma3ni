# Build-in-Public Plan — LinkedIn

Goal: be known as the engineer who built Tunisian speech recognition people actually use. Positioning: **full-stack engineer → ML/AI engineer, shipping real products for MENA users.**

## Rules
- 1 post per week, same day (e.g. Tuesday 9:00 Tunis time)
- Always one **visual**: chart, demo GIF, architecture diagram, before/after transcript
- Real numbers (WER, latency, users) beat adjectives
- Write in English (reach), add a short Darija/French line for local engagement
- End with a question to drive comments
- Link GitHub / Hugging Face in the first comment, not the post body
